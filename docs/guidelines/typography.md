# Typography

One family, two voices: **Alegreya**, born from calligraphy, by Juan Pablo del Peral.

- **Alegreya Sans** for headings and everything you act on: buttons, tables, forms, labels.
- **Alegreya** (the serif) for text to read.
- **Alegreya italic** for process notes.

## Scale

| Token               | Size    | Use                           |
| ------------------- | ------- | ----------------------------- |
| `font-size-display` | 4rem    | A cover title                 |
| `font-size-h1`      | 2.75rem | Page title                    |
| `font-size-h2`      | 2rem    | Section                       |
| `font-size-h3`      | 1.5rem  | Block                         |
| `font-size-body`    | 1.25rem | Text                          |
| `font-size-small`   | 1rem    | Captions, field help, footers |

Text sits at line height 1.6, headings at 1.08. Reading columns stay within `measure-reading`.

## Avoid

- All caps for labels, or tracked-out eyebrows above headings.
- One word of a heading in another color or weight.
- Monospace for anything but code.
