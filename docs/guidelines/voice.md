# Voice

**A living workshop**: somewhere between a craftsperson's bench and a busy workshop. Interfaces
built with Feitio show the care of whoever made them and the will to keep going.

## Values

- **Refinement.** Detail nobody asked for, few elements, each one well finished. If it does not
  help, it goes.
- **Process.** The marks of the work stay in sight when they help to understand: what changed, why,
  what comes next. A process note (`feitio-note`) explains a decision; it is never decoration.
- **Energy.** The orange is movement. It marks the main action, what just changed, what needs
  attention, and nothing else.

## Never

- **Techy.** No neon, no glowing dark backgrounds, no terminal grids, no monospace as decoration.
  It should feel like a workshop, not a server room.
- **Convoluted.** One column, one idea per block, few kinds of component. If something needs an
  explanation to be used, it is wrong.
- **Noisy.** Orange appears rarely so it means something. Motion answers an action; at most one
  moment of motion per page arrives on its own.

## Writing

- Direct and warm, with action verbs. Speak to the person, not about the system.
- A button says what happens: **Save changes**, not _Submit_. The action keeps its name through the
  flow: a **Publish** button leads to a _Published_ notice.
- An error does not apologize and is never vague: say what happened and how to fix it.
  _The connection dropped. Your data is saved; try again._, not _Oops! Something went wrong._
- An empty screen invites action: _No tasks here. Create the first one._
- Sentence case, plain words, no filler.
